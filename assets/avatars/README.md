# Storybook demo avatars

Generated on 2026-09-25 with the built-in OpenAI imagegen tool, one separate call per portrait. These are entirely fictional adults; no user photos or real-person references were used.

Purpose: local Storybook demo assets only. Previews import optimized 256 × 256 WebP files (quality 80), totaling 18,366 bytes. Original generated PNG files are retained as sources and are not imported into the Storybook build. The avatar components provide the circular or rounded frame in the preview.

The prompts requested square 512 × 512 output where available. The tool returned four native **1254 × 1254 PNG** images; those dimensions are preserved. Each portrait was visually inspected: one centered adult, matching studio lighting and plain clothing, the requested background, no text or watermark, and a face suitable for circular cropping.
